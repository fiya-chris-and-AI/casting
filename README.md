# CASTING — app

This folder is the Next.js app. **The full README — what CASTING is, the four YouCam APIs it uses, setup, architecture, and the honesty section — lives at the [repository root](../README.md).**

Quickstart:

```bash
cp ../.env.example .env.local   # paste your YOUCAM_API_KEY
npm install
npm run dev                     # → http://localhost:3000
```
